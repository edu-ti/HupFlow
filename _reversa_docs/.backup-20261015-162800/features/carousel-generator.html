Visão Geral

O **Carousel Generator** é um microsserviço web projetado para transformar tópicos, textos e artigos em carrosséis visuais estruturados para redes sociais (LinkedIn e Instagram), utilizando OpenAI com function calling estruturado e geração de arquivos PDF e PNG.

---

Responsabilidades

  • Ingestão de prompts e artigos fornecidos pelo usuário.
  • Comunicação com a API OpenAI (`gpt-4o-mini`) exigindo validação estrita de esquema JSON (8 a 15 slides).
  • Controle de taxa de requisições (rate limiting) por endereço IP com Upstash Redis.
  • Edição interativa de temas, cores, tipografia e slides no navegador.
  • Exportação vetorial em PDF e captura estática em imagens PNG.

---

Regras de Negócio

  • **RN-CG-01**: A geração de carrosséis deve produzir obrigatoriamente entre 8 e 15 slides. 🟢 CONFIRMADO
  • **RN-CG-02**: Cada slide deve conter no máximo 70% do comprimento limite de caracteres de cada campo para evitar quebras em telas móveis. 🟢 CONFIRMADO
  • **RN-CG-03**: Os tipos de elementos permitidos em cada slide são estritamente `Title`, `Subtitle` e `Description`. 🟢 CONFIRMADO
  • **RN-CG-04**: Emojis contextuais devem ser injetados nos títulos e subtítulos gerados pela IA. 🟢 CONFIRMADO
  • **RN-CG-05**: Não adicionar numeração estática de slides no texto dos elementos (a paginação é dinâmica). 🟢 CONFIRMADO

---

Fluxo Principal de Execução

1. O componente `AIInputForm` captura o texto do prompt e dispara a Server Action `generateCarouselSlidesAction`.

2. A action valida `process.env.OPENAI_API_KEY`. Se nula, encerra retornando `null`.

3. Se `KV_REST_API_URL` e `KV_REST_API_TOKEN` existirem, extrai o IP de `headers().get("x-real-ip")` e invoca `messageRateLimit.limit(ip)`.

4. Instancia `ChatOpenAI` configurado com `gpt-4o-mini`, `temperature: 0` e `functions: [carouselFunctionSchema]`.

5. Envia `SystemMessage` com diretrizes de tamanho e emojis, acompanhada da `HumanMessage` com o prompt do usuário.

6. Realiza `JSON.parse` nos argumentos da função chamada.

7. Executa `UnstyledDocumentSchema.safeParse`. Se válido, retorna `MultiSlideSchema.parse(slides)`.

---

Dependências

  • `langchain`: Biblioteca de orquestração de chamadas de LLM.
  • `@upstash/ratelimit` e `@upstash/redis`: Rate limiter distribuído HTTP.
  • `@react-pdf/renderer`: Geração vetorial do documento em formato PDF.
  • `html-to-image`: Rasterização de nós DOM do navegador em canvas/imagens PNG.

---

Riscos e Lacunas

  • 🔴 **LACUNA**: Falta de retorno amigável de mensagem de erro para o frontend quando o rate limit é atingido (retorna apenas `null`).
  • 🟡 **INFERIDO**: Dependência externa direta da API da OpenAI sem fallback para outros modelos (como Claude ou Ollama local).
