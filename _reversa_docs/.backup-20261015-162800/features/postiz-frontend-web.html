Visão Geral

O **Postiz Frontend Web** é a interface do usuário da plataforma de mídias sociais, desenvolvido em Next.js 16, React 19, Mantine UI e Tailwind CSS, oferecendo calendário editorial dinâmico, editor de postagens com pré-visualização fiel por rede social e métricas de alcance.

---

Responsabilidades

  • Apresentação do painel de controle (Dashboard) com visualização em grade semanal e mensal.
  • Editor avançado de conteúdo suportando múltiplas mídias, emojis, menções e tags.
  • Pré-visualização contextual fiel de como a publicação aparecerá no X/Twitter, LinkedIn, Instagram, TikTok e Threads.
  • Integração de assistente de redação inteligente com CopilotKit.
  • Autenticação de usuário e seleção de organização ativa.
  • Proxying de requisições (`proxy.ts`) para isolamento seguro do backend.

Estrutura do App Router

  • `src/app/(app)`:
  • `(site)`: Páginas protegidas: calendário, posts, analytics, integrações, billing e settings.
  • `auth`: Fluxos de autenticação, login, registro e recuperação.
  • `oauth`: Páginas de recepção de callbacks de provedores externos.
  • `src/proxy.ts`: Intercepta requisições para `/api/*` e roteia internamente para `BACKEND_INTERNAL_URL` mantendo tokens de sessão seguros e evitando problemas de CORS.

---

Stack de UI e Componentes

  • **Next.js 16** com React 19 Server e Client Components.
  • **Mantine UI 5** para inputs complexos, modais e seletores de data/hora.
  • **Tailwind CSS 4** para estilização utilitária de temas escuro/claro.
  • **CopilotKit** para autocomplete e chat contextual de geração de postagens.

---

Riscos e Lacunas

  • 🟡 **INFERIDO**: A folha de estilos `polonto.css` (397 KB) presente no frontend sugere uma integração legada ou futura com o editor Polotno Studio diretamente embutido na web.
