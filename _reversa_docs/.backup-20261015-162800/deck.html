Visão Geral & Desafio

Unificando a Fragmentação de Conteúdo

Criadores de conteúdo e agências utilizam ferramentas isoladas: um app para carrosséis, outro para artes visuais e plataformas terceirizadas caras para agendamento.

A Solução HupFlow: Um monorepo distribuído que une geração de copy por IA (Carousel Gen), estúdio gráfico assistido por agentes (Polotno MCP) e motor corporativo de despacho multicanal (Postiz).
Subsistema 1

Postiz: Workflows Duráveis com Temporal.io

Em vez de depender de cron jobs vulneráveis a quedas de servidor ou rate limits momentâneos, o Postiz adota o Temporal.io:

Idempotência Absoluta

WorkflowId mapeado ao PostId; zero duplicação de publicações.

Renovação OAuth Autônoma

Tokens prestes a expirar são renovados em segundo plano antes do disparo.

38 Conectores Sociais

X, LinkedIn, Meta, TikTok, Bluesky sob interface polimórfica única.

Subsistema 2

Polotno Studio & Model Context Protocol

Um ambiente desktop de alta performance (Electron 39 + Konva + React 19) onde humanos e agentes de IA colaboram na mesma tela.

Nativo em MCP: Modelos de linguagem manipulam camadas, ajustam textos, executam linter de contraste e despacham artes diretamente para o Postiz via tool export_to_postiz.
Subsistema 3

Carousel Generator: Carrosséis com IA

Engenharia de prompts estruturada com LangChain e OpenAI gpt-4o-mini. Gera 8 a 15 lâminas com métricas visuais balanceadas para leitura em mobile.

Proteção de Rate Limit

Upstash Redis KV com respostas amigáveis e contadores por IP.

Bring Your Own Key (BYOK)

Fallback elegante permitindo ao usuário usar sua própria API Key.

Topologia & Dados

Arquitetura Distribuída & Fronteiras

Isolamento lógico estrito por OrganizationId no PostgreSQL via Prisma. Nenhuma requisição cruza dados entre tenants.
