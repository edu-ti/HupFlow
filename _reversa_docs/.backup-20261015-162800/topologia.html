Topologia do Sistema: 3 Pilares Integrados

O HupFlow combina três subsistemas complementares em uma esteira única de ponta a ponta: geração de cópias/carrosséis com IA, criação visual 2D desktop via MCP e agendamento durável multi-tenant para 38 redes sociais.

🎨

Carousel Generator

Next.js 14 Web

Gerador automatizado de lâminas verticais/quadradas para LinkedIn e Instagram. Converte temas e artigos em sequências prontas para conversão social.

  • Motor de IA: LangChain + OpenAI gpt-4o-mini
  • Controle de Cota: Rate Limit por IP (Upstash Redis) + BYOK
  • Exportação: PDF Vetorial e PNG cliente-side
🖥️

Polotno Studio App

Electron 39 Desktop

Estúdio completo de design 2D offline-first com Konva e Polotno SDK. Equipado com servidor nativo MCP para manipulação assistida por agentes de IA.

  • Canvas: Konva 10 + Polotno SDK + MobX 7
  • Protocolo IA: Model Context Protocol (MCP) JSON-RPC
  • Bridge Postiz: Tool export_to_postiz para upload direto
🚀

Postiz Social Engine

NestJS 11 + Temporal

Plataforma corporativa de agendamento, faturamento multi-tenant e disparo automatizado com workflows duráveis para 38 redes sociais integradas.

  • API & Banco: NestJS 11, Prisma ORM, PostgreSQL
  • Orquestrador: Temporal.io Workers para jobs duráveis
  • Canais: 38 adaptadores sob interface SocialAbstract

Fluxo Operacional de Produção e Publicação

1

Ideação & Geração Estruturada (Carousel Generator)

O usuário submete um tema. O LangChain gera entre 8 e 15 lâminas com formatação estrita Zod. O Upstash Redis garante proteção contra sobrecargas e excesso de custos de API.

2

Refinamento Visual & Assistência por Agente (Polotno Studio)

O criador ou um agente autônomo (via servidor MCP local) abre o design, ajusta elementos no Konva, aplica linter de contraste e proporções e aciona a tool export_to_postiz.

3

Composição & Validação Editorial (Postiz Frontend)

No calendário interativo, o post recebe copy adaptada, tags, seleção de múltiplos canais sociais (Sets) e horário de publicação programado.

4

Orquestração Durável & Despacho Multicanal (Temporal.io)

No milissegundo exato, o Temporal dispara a activity idempotente. Se o token OAuth estiver próximo de expirar, um workflow filho renova as credenciais e conclui a entrega com retentativas automáticas.
