Visão Geral

O **Polotno Studio Core** é uma aplicação desktop offline-first e editor gráfico web construído sobre Electron, Vite, React 19 e SDK Polotno, dedicado à criação e edição visual em alta performance de banners, posts e peças gráficas para mídias sociais.

---

Responsabilidades

  • Renderização e manipulação 2D de elementos visuais no canvas via Konva e Polotno SDK.
  • Gerenciamento reativo de estado de prancheta, abas e histórico de desfazer/refazer via MobX.
  • Ciclo de vida da aplicação desktop multiplataforma (Windows, macOS, Linux) com Electron.
  • Leitura e persistência de arquivos `.polotno` na pasta do usuário (`Documents/Polotno`).
  • Exportação vetorial e rasterizada para PDF, PNG, JPEG e SVG.
  • Execução de comandos CLI headless (`render`, `lint`) sem interface gráfica.

---

Regras de Negócio

  • **RN-PSC-01**: A aplicação deve garantir bloqueio de instância única (`single-instance lock`). Tentativas de abrir nova janela trazem a janela ativa para frente e abrem os arquivos solicitados como novas abas. 🟢 CONFIRMADO
  • **RN-PSC-02**: Todas as criações e edições são salvas de forma local-first; nenhum dado de design trafega obrigatoriamente para servidores externos. 🟢 CONFIRMADO
  • **RN-PSC-03**: Os comandos CLI headless `render` e `lint` desviam a inicialização antes de qualquer janela ser criada, garantindo execução leve em servidores e pipelines de CI. 🟢 CONFIRMADO

Estrutura de Processos Electron

1. **Processo Principal (Main Process)**:

  • Controla o ciclo de vida da janela (`BrowserWindow`), menus nativos e atalhos de teclado.
  • Gerencia a comunicação IPC entre o sistema operacional e a webview.
  • Inicializa a ponte Bridge Router para receber chamadas de automação externas.

    • 2. **Processo de Renderização (Renderer Process)**:

  • Instancia o `createStore()` do SDK Polotno.
  • Aplica MobX como motor reativo para sincronização da prancheta e componentes React 19.
  • Renderiza a árvore de nós no elemento HTML5 Canvas com Konva.

---

Formato de Arquivo de Design (Design JSON)

O formato persistido em disco obedece estritamente ao contrato serializado do Polotno SDK:

```json

{

"width": 1080,

"height": 1080,

"pages": [

{

"id": "page-1",

"children": [

{

"id": "text-1",

"type": "text",

"text": "Título do Post",

"x": 100,

"y": 150,

"fontSize": 48,

"fill": "#ffffff"

}

]

}

]

}

```

---

Dependências Críticas

  • `polotno`: SDK de manipulação gráfica vetorial.
  • `konva`: Motor 2D de canvas.
  • `mobx` e `mobx-react-lite`: Gerenciador de estado reativo da aplicação.
  • `electron` e `@electron-toolkit/utils`: Camada de compatibilidade de sistema operacional.

---

Riscos e Lacunas

  • 🟡 **INFERIDO**: Suporte a exportação de vídeo MP4/GIF requer ferramentas nativas compiladas no ambiente de build (`ffmpeg` ou codecs embutidos).
